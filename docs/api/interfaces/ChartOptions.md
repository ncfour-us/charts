# Interface: ChartOptions

Options for any chart

## Extended by

- [`ChartParms`](ChartParms.md)
- [`XYLineChartOptions`](XYLineChartOptions.md)
- [`BarChartOptions`](BarChartOptions.md)
- [`DonutChartOptions`](DonutChartOptions.md)

## Properties

### backgroundColor?

> `optional` **backgroundColor?**: `string`

background color for rasterized charts, defaults to 'rgba(255,255,255,1)' (white)

***

### logger?

> `optional` **logger?**: `ILogger`

optional logger for the Chart object to use

***

### title?

> `optional` **title?**: `string`

title for the chart, defaults to 'Chart Title'
